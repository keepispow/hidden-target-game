# 手札全開示ゲーム（仮称）

1対1の心理戦ボードゲームです。  
**手札を基本的に公開したまま**進め、盤上の「的（まと）」を守り、相手の的を先に踏むと勝ちになります。

ブラウザだけで遊べます（HTMLファイル1つ）。  
**同じ端末でのパス＆プレイ**と、**ルームコードによるオンライン対戦**の両方に対応しています。

---

## このゲームは何を争うのか

各プレイヤーはゲーム開始前に、自陣の一番奥の列から **秘密の1マス＝的** を決めます。

- **攻め**：自分の駒を相手の的のマスまで運ぶ
- **守り**：罠・駒・カードで相手の侵入を阻む

相手の的に駒が到達した瞬間、そのプレイヤーの勝利です。  
山札が双方尽きても決着しない場合は、的への近さ・残りHPなどで判定します。

「情報はだいたい見える。だからこそ、伏せと配置とタイミングが勝負」——というのがコンセプトです。

---

## 盤面

全体は **縦9 × 横5** のマスです。

```
行1〜4   プレイヤー2の陣地（一番奥＝行1が的の列）
行5      緩衝地帯（初期配置不可。移動では入れる）
行6〜9   プレイヤー1の陣地（一番奥＝行9が的の列）
```

- **的の列**（各陣地の一番奥）には、駒も罠も **置けません**
- 的そのものは、その列の5マスから1つだけ秘密に選びます
- 駒と罠は同じマスに重ねて置けます（1マスあたり駒1・罠1まで）

---

## 駒

| 種類 | 数 | HP | 攻撃力 |
|------|----|----|--------|
| 小駒 | 3  | 2  | 1 |
| 中駒 | 2  | 4  | 3 |
| 大駒 | 1  | 6  | 5 |

- 1ターンに動かせる駒は **最大3体**
- 移動範囲：**前後左右に最大2マス** ＋ **斜めに1マス**
- 移動経路上に敵駒がいれば **戦闘**、敵の罠があれば **罠発動**（そのマスで停止）
- 相手の駒は種類が分からない表示になります（索敵や情報罠などで判明）

戦闘はお互いに攻撃力分のダメージを同時に与えます。  
カードや罠の強化・デバフで数値が変わります。

---

## 罠

準備フェイズで自陣に **10個** 配置します。ゲーム中もカードで追加設置できます。

| 種類 | 効果の概要 |
|------|------------|
| ダメージ | 踏んだ駒にダメージ（強化で増加） |
| デバフ   | 次の戦闘で被ダメージ増加など |
| 情報     | 踏んだ駒の種類・伏せ札・山札情報などを設置者に公開 |
| ドロー   | 設置者がカードを1枚引く |

**共通**：踏んだ駒はそのターン行動終了になります。  
発動した罠は盤面から除去され、カード「罠再起動」で再設置できることがあります。

敵駒の周囲8マスには、ゲーム中の新規設置ができません（初期配置の罠は自陣ルールに従います）。

---

## 手札・カード

- 各プレイヤー **30枚デッキ**（先攻用・後攻用で構成が少し違う）
- 初期手札 **6枚**。手札は基本的に相手からも見えます
- 1ターンに使えるカードは **最大3枚**（「温存」で追加可能）
- **伏せ**：同時に最大3枚まで、相手に内容を見せない伏せ状態にできる  
  - 後攻のみ、準備で最初の伏せフェイズあり  
  - 本編中も伏せ／公開の切り替え可
- **使用したカード**は捨て札にすぐ行かず、**伏せ状態で手札に残る**  
  → 自分の次のターン開始時に捨て札へ移り、その分を補充

### カードの大まかな役割

- **駒強化** … 攻撃・HP・一時バフ、決死の特攻など
- **罠強化** … ダメージ増加、デバフ延長、再設置、改造
- **罠そのもの** … 盤上に新しい罠を置く
- **情報** … 索敵、伏せ札確認、的の手掛かり、罠読みなど
- **ドロー** … 補給、温存、条件付きドロー
- **大駒専用・その他** … 回復、防衛線、先制、戦闘継続など

詳細はゲーム内の「カード・罠一覧」ボタンから確認できます。

## セットアップの流れ

1. プレイヤー名入力（ローカル）／ルーム作成・入室（オンライン）
2. 先攻・後攻の決定
3. （後攻のみ）手札を最大3枚まで伏せる
4. 的の選択（各プレイヤー、自陣奥列から1マス）
5. 駒の配置（各6個・自陣。的の列には不可）
6. 罠の配置（各10個・自陣。的の列には不可）
7. 本編開始

パス＆プレイ時は、相手に画面を見せないための **全画面ゲート** が入ります。  
オンライン時は、**相手の操作中は自分の画面を隠す待ち画面** になります。

---

## ターンの流れ（本編）

1. 駒を動かす（最大3体）／カードを使う（基本最大3枚）
2. 戦闘・罠・カード効果が解決される
3. ターン終了  
   - 使用カードは伏せて手札に残る  
   - カードを1枚も使わなかった場合、山札の一番上が強制で捨て札に
4. 相手ターンへ  
   - 相手のターン開始時に、前回使用分が捨て札になり、補充される

## 遊び方（起動）

### ローカル（パス＆プレイ）

1. `hidden-target-game.html` をブラウザで開く  
2. 「ローカル対局を開始」  
3. 同じ端末を交互に操作（ゲートの指示に従って端末を渡す）

### オンライン（ルームコード）

1. **HTTPSのURL** で開く（GitHub Pages など）  
   ※ iPhoneでファイルを直接開くと真っ黒になりやすいです
2. ホストが「部屋を作る」→ 6文字コードを共有  
3. 相手がコードを入れて「部屋に入る」  
4. 接続後、ホストが「対局を開始」

- ホスト＝プレイヤー1、入室側＝プレイヤー2  
- 通信は PeerJS（インターネット経由のP2P）の最小実装です

## 画面操作のヒント

| 操作 | 内容 |
|------|------|
| マスをタップ | 配置・移動・対象選択 |
| 右クリック／長押し | そのマスの情報 |
| 「自分の罠を表示」 | 自分の未発動罠を盤上に表示 |
| 「的を表示」 | 自分の的の位置を確認 |
| 「カード・罠一覧」 | 全カード・罠の参照 |
